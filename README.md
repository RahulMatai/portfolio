# 🚀 AI-Powered Portfolio Website

A modern developer portfolio website featuring an interactive AI assistant trained on my professional experience, resume, projects, and technical background.

The goal of this project is to create a smarter and more engaging portfolio experience where recruiters and visitors can directly interact with an AI agent to learn more about me, my work, and my skills.

---

## ✨ Features

### 🤖 AI Recruiter Assistant
An integrated AI chatbot trained on:
- My resume
- Professional experience
- Technical skills
- Projects
- Career journey

Visitors can ask questions such as:
- "What technologies does Rahul work with?"
- "Tell me about his Microsoft internship"
- "What cloud platforms has he used?"
- "Explain his projects"

The AI responds dynamically based on the trained data and acts as an intelligent recruiter assistant.

---

### 💼 Featured Projects
Showcases my top 3 highlighted projects with:
- Project descriptions
- Key features
- Problem-solving approach
- Live demos / GitHub links

---

### 🎨 Modern UI/UX
- Responsive design
- Smooth animations
- Interactive components
- Clean and professional layout
- Optimized for desktop and mobile
